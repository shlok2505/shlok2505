## 🔥 Featured projects

### 🛍️ [JAS – Clothing E-Commerce](https://jas-sarees.vercel.app/)
A live, cloud-deployed saree e-commerce platform built for my mother's business, Jai Ambe Sarees. Catalogue listing, browsing and orders in one end-to-end workflow, with AI-generated order descriptions so the seller fills in fewer details.
`Next.js` `Spring Boot` `PostgreSQL (Neon)` `Cloudinary` `Vercel` `Render`

### 👣 [Footprints – Leave Your Presence](https://github.com/shlok2505/iwh)
A full-stack mobile app where users leave a personal "Footprint" or a "Presence" at a physical location for others to find.
`Flutter` `Dart` `Spring Boot` `Spring Data JPA` `PostgreSQL`

### 🏠 [Vinyasa – Single Room Image to 3D Model](https://github.com/shlok2505/vinyasa)
Turns one room photo into an editable 3D scene: YOLOv8 extracts furniture crops, TripoSR reconstructs each object as a mesh, and scenes render in Three.js.
`Python` `YOLOv8` `TripoSR` `Three.js`
